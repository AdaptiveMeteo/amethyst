The aim of Wrf2FirstGuess
--------------------------

This software package has been written as an auxiliary software for the Mirto project. Mirto is an open-source software that

A "first guess" for Mirto is a file that contains a initial guess for the values that the software is going to produce. A first guess contains in particular
two kinds of information:

  - *Atmospheric Information*: The amount of oxygen, water vapour, ozone, ... in some specific points of the atmpshere
  - *Ground Information*: The IGBP class and the emissivity of the ground for each different point where the retrival must be computed


Wrf2FirstGuess prepares the atmospheric part of a first guess, using data generated by a WRF model.

To perform the computation, it needs the exact positions (in terms of latitude and longitude) of each point where the retrievals will be computed
and, of course, a WRF file with the data from the model.

The positions are retrieved from an observation file (the Mirto input file with the data of the instrument).

For the WRF model, different sources can be selected. Actually, the only source available is "local_file", which means that the software will look for a
particular file on your hard disk. In the future, we hope to extend this functionality, allowing the software to download automatically the necessary data
from a remote repository.


Requirements
------------------
Wrf2FirstGuess has been written for linux. Even if it MIGHT work with other operating systems, it has never been tested nor has been written
for this intent.

Moreover, to be able to run Wrf2FirstGuess, you should have the following software installed: 

- Python 2.7 (it should work also with Python 3, but has not been tested)
- Numpy >= 1.9
- Scipy >= 0.13
- NetCDF4 for python
- Supersmoother (https://pypi.python.org/pypi/supersmoother)


How to install
------------------
This software do not requires any installation. It you have the Wfr2FirstGuess directory in your machine, then you can launch the software.


How to test
------------------
Before running the first time the software, it is a good idea to run some test to be sure that everything is working as expected. To run the test,
execute the command ::

  nosetests -x

in the main directory of the program.


How to run
---------------
The software can be executed by calling your python interpreter over the main script. Usually it should be ::

  python wrf2firstguess.py

With the -h flag, you can have a brief description of the syntax of the software. The most common one usually is ::

  python wrf2firstguess.py observations output -i wrf_input_file

where:

 - observations is the path of the observation file the observations will be read from
 - output is the path to the file that will be written by the software. Please, read the `How the output is saved`_ section  to
   get more information about how the output is written
 - wrf_input_file is the path of the wrf file that will be used to generate the first guess

Please note that, by default, the source is "local_file" so there is no need to specify it again in the command line.

How the output is saved
------------------------
Wrf2FirstGuess only generates the atmospheric part of the First Guess. Therefore, you need to "complete" the output file with the
data related to the superficial temperature, that, in principle, you might already have generated.

For this reason, if the output file does not exist, Wrf2FirstGuess will create a NetCDF file with the atmospheric data.
Otherwise, if the file already exists, Wrf2FirstGuess will try to integrate the data that it generates in the very same file.

If the atmospheric part is already present in your file, wrf2firstguess will *not* overwrite it, but it will return an error.
